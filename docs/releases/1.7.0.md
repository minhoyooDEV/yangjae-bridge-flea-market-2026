# v1.7.0

## 변경 사항

- `AGENTS.md`와 `CLAUDE.md`를 동일한 공통 규칙으로 통합했습니다. 기존 프로젝트 배포 규칙과 로컬 Ruflo 가이드를 함께 유지했습니다.
- 규칙 변경 시 두 파일을 같은 PR에서 동일하게 수정하도록 명시했습니다.
- 버전 업데이트마다 `docs/releases/<버전>.md` 작성이 필수이며 변경 사항·검증·배포 정보를 기록하도록 했습니다.
- `pnpm rules:check`가 규칙 파일 일치, 루트·웹 버전 일치, 현재 버전 릴리스 노트의 제목과 필수 내용을 검증합니다. PR/Pages에서 실행되는 `pnpm test`에 연결했습니다.

## 검증

- 자동 검증 대상: 정상 구성, 한쪽 규칙 변경, 릴리스 노트 없는 버전 증가, 패키지 버전 불일치, 잘못된 노트 제목, 빈 노트 항목.
- 로컬 검증: frozen-lockfile 설치, 규칙 검사, 테스트 39개, 포맷 검사, GitHub Pages 하위 경로 빌드 통과.
- PR 검사에서 frozen-lockfile 설치, 규칙 검사, 전체 테스트, 포맷 검사 및 웹 빌드가 모두 통과해야 병합합니다.

## 배포

- 별도 작업 브랜치의 PR로 main에 병합하고 GitHub Pages workflow로 배포합니다.
- `v1.7.0` 태그는 병합된 main 커밋에 생성합니다. 배포 성공 여부는 해당 커밋의 Actions 결과와 공개 URL로 확인합니다.
- GitHub의 브랜치 보호 설정은 이 변경에 포함하지 않습니다. 규칙 문서와 CI 검사를 추가하며 관리자 권한으로 보호 규칙을 변경하지 않습니다.
