## 의도된 DB 보안 점검 항목

`public.my_booth_id()`는 로그인한 업체가 자기 매대 UUID만 알아내도록 만든 SECURITY DEFINER 함수다. 인자를 받지 않고 `auth.uid()`로 제한하며 익명 실행은 불가하다. Supabase 보안 점검의 로그인 사용자 실행 경고 1건은 이 의도된 함수에 해당한다. 계정 할당 함수는 서버 역할만 실행할 수 있다.
