## 연출

30초. 핵심 스토리는 ‘처진 허브 → 제품 조립 → 물 채우기 → 수분 전달 → 생기를 되찾는 허브 → 식탁’이다. 책자가 화면 중앙에 놓이고 오른쪽 페이지가 왼쪽으로 넘어간다. 페이지 가장자리가 먼저 들리고, 종이가 휘면서 뒷면과 그림자가 나타난다. 페이지 위에서 제품 부품과 허브가 팝업북처럼 입체적으로 움직인다. 조립과 물의 이동은 한 장 안에서 연속적으로 보여주고, 이야기의 단계가 바뀔 때 책장을 넘긴다. 따뜻한 종이색과 허브의 초록색을 사용한다. 자막만으로도 내용을 이해하도록 구성한다.

사진은 원본 자료로 사용한다. 영문 설명 전체를 작은 크기로 노출하는 대신 핵심을 한국어로 재구성한다. 제품 형태와 브랜드는 원본에 맞춘다. 실제 사진 사용 영역과 도해 영역을 구분한다.

## 움직임과 소리

- 조립: 부품이 천천히 내려와 맞물리며 부드러운 접촉음. 패드 설치 순서를 생략하지 않는다.
- 급수: 물줄기와 수위 상승에 짧은 물소리를 맞춘다.
- 수분 전달: 패드 경로만 강조해 제품 구조를 이해하게 한다.
- 허브 변화: 잎의 각도와 탄력이 서서히 달라진다. 마른 갈색 잎이 즉시 초록으로 바뀌는 연출은 사용하지 않는다.
- 책장 전환: 종이 마찰음과 이동 그림자를 맞춘다. 음악은 잔잔하게 시작해 허브가 펼쳐지는 부분에서 밝아진다.

허브 회복 장면은 수분이 부족한 상태의 변화를 설명하는 개념 연출이다. 제공된 자료에는 시든 허브의 회복 실험이나 소요 시간이 없으므로 실제 전후 결과처럼 제시하지 않는다. 해당 장면에 ‘이해를 돕기 위한 연출’을 작게 표시하고 특정 회복 시간을 표기하지 않는다. 마지막 관리 문구는 ‘물 높이를 주기적으로 확인하고 보충해주세요.’로 유지한다.

## 구현 방향

최신 소스는 `/Users/myno/Documents/yangjae-bridge-flea-market-2026`에 있으며 GitHub main의 `5463da2`와 일치했다. 이를 현재 작업 폴더의 `video-workspace`에 별도 복제하고 `feat/herb-keeper-film` 브랜치에서 구현했다. 기존 작업 폴더의 소스는 덮어쓰지 않았다.

초안은 추가 패키지 설치 없이 Swift/CoreGraphics의 프레임 렌더러와 FFmpeg로 구현했다. Remotion을 사용한 결과물은 아니다. 편집 가능한 소스는 `scripts/film/render.swift`, 직접 합성한 음악·효과음은 `scripts/film/audio.py`, 재생성 명령은 `bash scripts/film/render.sh`이다. macOS의 Swift, Python 3, FFmpeg가 필요하다. 페이지 전환은 휘어진 종이 면의 명암과 이동 그림자로 표현했다.

최종 장면은 레시피 그림 대신 1구 제품과 관리 안내로 마무리한다. 사이트에는 `HerbKeeperFilm` 컴포넌트를 추가했고 `burwell-herb-keeper-single` 상세에서만 표시한다. 자동재생하지 않으며 재생 버튼을 눌러 감상한다. 영상은 자막이 포함된 1280×720 / 30fps / H.264 + AAC / 30초 / 약 1.12MB이다. 내용의 텍스트 대안도 제공한다.

## 남은 작업

- 완료: 배포 소스 확인, 작업본 분리, 영상 소스 작성, MP4 출력, 상품 상세 연결, 주요 프레임 육안 검수, 전체 파일 디코딩 검사, 빌드 성공 및 기존 테스트 31개 통과.
- 로컬 서버는 실행 환경의 포트 열기 제한(EPERM)으로 시작하지 못했다. 브라우저에서 상품 상세의 실제 영상 재생과 모바일 레이아웃은 아직 확인하지 못했다.
- QuickTime Player 접근은 허용되지 않아 앱 재생 및 청취 검수는 하지 않았다. 오디오 스트림과 음량은 파일 분석으로 확인했다.
- 독립 미리보기는 `video-workspace/public/films/preview.html`로 제공한다. 브라우저 도구의 보안 정책이 file URL 열기를 차단해 이 미리보기의 브라우저 검증도 진행하지 않았다.
- 최종 MP4는 30.000초, 1,122,353바이트이며 전체 디코딩 검사를 통과했다. GitHub Pages 하위 경로를 지정한 프로덕션 빌드도 통과했다.
- GitHub Pages 배포는 하지 않았다. 영상 초안 검토 후 배포 가능하다.

## 모노레포 전환 (2026-10-05)

위 제작 기록의 `video-workspace`는 이후 통합되었다. 현재 웹 코드는 `apps/web`, 영상 소스는 `packages/herb-film/scripts`, 완성 영상은 `packages/herb-film/assets`에 있다. 루트 `pnpm film:render`로 재생성하며 `pnpm build`는 영상 파일을 웹으로 복사한다. 이전 독립 작업본은 `.local/pre-monorepo/video-workspace`에 보관하고 내부 Git 메타데이터 이름을 `git-metadata`로 바꿔 활성 중첩 저장소를 제거했다.

모노레포 전환 검증에서는 로컬 웹 서버가 정상 실행되었고 Chrome에서 상품 상세 영상이 30초 끝까지 재생됨을 확인했다. 이전 제작 시점의 로컬 서버·재생 제한은 현재 검증에는 해당하지 않는다.
