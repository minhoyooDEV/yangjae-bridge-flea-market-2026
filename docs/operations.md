# 1.x.x 운영 안내

한 매대의 정적 원페이지를 운영한다. 로그인, DB, 관리 화면은 없다.

1. `src/data/market.ts`에 실제 매대 정보와 상품명·가격·상세 설명을 입력한다.
2. 매대 사진과 선택적인 상품 사진을 `public/`에 추가하고 데이터의 이미지 경로를 수정한다.
3. 예시 정보를 실제 정보로 교체한 후 `booth.is_sample=false`로 설정한다.
4. 로컬 테스트와 빌드 후 main에 반영한다. GitHub Actions가 GitHub Pages에 배포한다.
5. 배포된 사진·가격·모달과 현장 QR 접근을 확인한다.

데이터 수정은 코드 수정과 재배포로 반영한다. 실제 판매 정보가 없는 현재 데이터는 예시로 표시한다.

자세한 설정은 [배포 워크플로우](beta-workflow.md)를 참고한다. Supabase 연결·로그인·업체 관리·DB 마이그레이션 및 기존 운영자 스크립트는 2.x.x 도입 시 검토한다. 1.x.x에는 API 키나 업체 계정이 필요하지 않다.
